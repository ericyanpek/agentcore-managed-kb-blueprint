# 支付滥用检测

信用卡盗刷通常表现为在短时间内对多个账号执行相同面值的充值，且收货地址或 IP 归属地与历史行为显著偏离。风控模型基于设备指纹、支付工具哈希和交易时序三个维度构建特征，使用梯度提升树在实时推理延迟 50ms 内给出拒绝或通过决策。

退款滥用是另一类高发风险：玩家完成充值后消耗虚拟货币，随后向支付渠道申请退款。系统通过"消耗时间窗口"策略缓解：充值后的虚拟物品或货币在 72 小时内无法提现或转让，退款申请触发时系统自动冻结对应资产并通知人工审核。退款成功后相关资产从账号余额中扣除，若余额不足则产生欠款记录。

高风险渠道（例如部分预付费卡发行商）的退款率阈值设置为 2%，超出后自动降低该渠道的单笔限额并上报支付合规团队。渠道风险评分每周滚动计算，新渠道接入前需通过为期 14 天的沙箱期观察，沙箱期内单日充值上限为正常限额的 10%。
